# Potato Browser for Homebrew

```sh
brew install --cask potatobrowser/tap/potato-browser
```

[Potato Browser](https://potatobrowser.com) is a Chromium-based browser for macOS that hides the
AI features of websites. The
[release workflow](https://github.com/potatobrowser/potato-browser/blob/main/.github/workflows/release.yml)
of [potatobrowser/potato-browser](https://github.com/potatobrowser/potato-browser) updates the cask
each time it publishes a release, so it always points at the signed builds on the Releases page.

Issues and pull requests belong in the [main repository](https://github.com/potatobrowser/potato-browser).
